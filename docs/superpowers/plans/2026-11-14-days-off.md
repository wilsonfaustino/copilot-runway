# Days off Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In workday mode, the user marks holidays and vacation days in a Settings calendar grid, and the runway skips them like weekends.

**Architecture:** A Core value type `LocalDay` (a calendar date) and a `daysOff: Set<LocalDay>` associated value on `RunwayDays.workdays`. `RunwayDays.isWorkday` checks it, so every Runway function follows with no caller change. Core `DaysOffGrid` lays out the cycle month for the view and expands shift-click ranges. `UsageStore` reads the `daysOff` key. The Settings Runway tab gets the grid; the popover gets one marker line.

**Tech Stack:** Swift, SwiftUI (macOS 15), Swift Testing, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-11-14-days-off-design.md`

## Global Constraints

- With no days off, every output stays byte for byte the same in both modes. Existing tests must pass unchanged, except call sites of `.workdays(tz)` that the new associated value forces to change.
- Day off = local date in the given `TimeZone`. App passes `TimeZone.autoupdatingCurrent`. Tests pass `TimeZone(identifier: "UTC")!` and `TimeZone(identifier: "America/Sao_Paulo")!`.
- Weekend dates are never days off. Dates outside the current cycle are ignored.
- UserDefaults key `daysOff`, value `[String]` of `yyyy-MM-dd`. Demo mode never writes it.

## Review Focus

1. A day off after the cursor when `date(addingDays:to:)` takes the whole-week jump (large counts early in a cycle or a large Portkey budget): the run-out date must still skip it.
2. Time zone: a day off in America/Sao_Paulo covers 03:00 UTC to 03:00 UTC next day; the last day of the cycle crosses the UTC reset.
3. Toggle "Count only weekdays" off with days off stored: calendar mode output unchanged; toggle back on: the marks return.
4. A stored date from last cycle after the reset: ignored by the math, not counted in the marker or the header.
5. All days of the remaining cycle marked off: days left and run-out must not loop forever or divide by zero.
